# GPT-IAYN

**GPT Is All You Need：由 GPT 在用户指导下完成的机器人训练实验。**

本项目公开的是宇树 G1 **0.8 米原地双脚背越式跳高 PPO 版**：从程序生成动作数据开始，经过 CEM 物理优化、示范录制、PPO 状态反馈训练，再导出模型并进行仿真验证。

项目不只包含训练入口，也包含生成数据的代码、被冻结的中间候选、示范数据、训练权重、验收逻辑和实验记录。助跑、感知、真人视频、GVHMR 与 GMR 属于后续独立实验，不在本次发布范围。

[MuJoCo 在线推理视频](media/g1-ppo-mujoco-online.mp4) · [PhysX 在线执行录像](media/g1-ppo-physx-online.mp4) · [英文首页与运行命令](README.md)

## GPT 做了什么

GPT 完成项目特定的场景与动作生成脚本、搜索与训练实现、调试、实验评估、模型导出和文档整理；用户提出目标、提供运行环境并持续评价和调整方向。

物理引擎、机器人模型、PPO 基础框架与深度学习库来自上游项目。名称表达的是 GPT 完成项目的实验方式，不代表这些基础算法都是 GPT 发明，也不代表机器人执行时调用 GPT。

## 数据从哪里来

1. **合成运动学种子**：设计关节关键帧、插值、初始根部运动；约 2.62 秒 / 131 帧。尚未证明能执行。
2. **CEM 物理优化**：优化 56 个曲线参数，通过执行器驱动机器人，检查腾空、过杆、接触、落地及电机限制。
3. **物理示范录制**：运行优化后的控制器，记录控制边界的实际关节、身体姿态、速度和目标角。
4. **PPO 在线采样**：给初始状态加入小扰动，学习在参考目标上增加状态反馈修正。

没有复制外部真人动捕文件，也没有下载一个现成的跳高策略。具体脚本、生成步骤和新候选的验收方法见 [DATA_GENERATION.md](docs/DATA_GENERATION.md)。

## 如何使用

只看冻结策略效果，安装 `requirements/eval.txt` 后执行：

```bash
python gpt_iayn.py restore
python gpt_iayn.py demo
MUJOCO_GL=egl python gpt_iayn.py demo --video --output artifacts/demo-video
```

`restore` 校验并恢复发布数据，按 SHA-256 从上游 mjlab 1.2.0 取得对应的 G1 网格。发布仓库不直接打包网格文件。输出视频是在线网络推理加物理仿真，不是逐帧写机器人位置。

训练使用独立环境，见 [INSTALL.md](docs/INSTALL.md) 和 [TRAINING.md](docs/TRAINING.md)。可以直接从冻结的 CEM 控制器重新生成示范，再训练 PPO；也可以重新生成合成种子并进行 CEM 搜索。随机搜索不保证在同一预算内得到同样的成功控制器。

## 网络与控制

Actor 输入 152 维：参考目标角、参考关节角与速度、实际关节误差与速度、重力方向、角速度和动作进度。网络是 256/256/128 隐藏层的 MLP，同一网络对实际状态和参考状态分别计算，再取差作为修正。保留固定参考前馈和时钟进度，并不是自主规划起跳的策略。

导出模块以 50 Hz 输出 29 个绝对关节目标角，底层以 400 Hz 运行 PD 和电机转矩—转速限制。实际世界位置、线速度和接触真值不进入 actor；训练奖励和 critic 可以使用仿真真值。

## 结果应当怎样理解

最终发布增益为 0.5。native MuJoCo 小扰动为 19/50、大扰动为 3/50；PhysX 有经过增益标定的一条 nominal 通过记录，最小间隙约 1.9 毫米。尚未证明广泛鲁棒性，没有真机测试。旧 CEM 的 19/20 不能当作 PPO 成功率。
