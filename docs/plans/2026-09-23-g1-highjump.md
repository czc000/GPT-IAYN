# G1 Fosbury-style high jump implementation plan

Goal: Train an actuated G1 to take off from ground, pass a physical crossbar back-first, and land on a mat; export a genuine dynamic MuJoCo rollout video and quantitative pass/fail evidence.

Architecture: An isolated project uses installed mjlab/BeyondMimic tracking and PPO on GPU 7. A procedural reference seeds the task, with no root forces or state overwrites during evaluation. GPU MuJoCo-Warp training transfers the frozen network to a separate standard MuJoCo CPU stepping loop. This is explicitly Warp-to-native-MuJoCo transfer, not Isaac-to-MuJoCo.

Alternatives: reward-only discovery needs substantially more exploration; human video reconstruction adds uncertain scale/timing/retargeting. Use a procedural reference initially and revise it based on dynamic evidence. Existing MotionDecode jumping samples are optional source material, not claimed to be Fosbury demonstrations.

1. Infrastructure: use the already-extracted NVIDIA 580.173.02 libraries for this process only. Preserve system driver and existing repos. Verify CUDA operation before launch.
2. Tests: verify reference shape, normalized quaternions, finite velocities and joint limits. Verify evaluator rejects bar touches, going underneath/around, partial-body crossings, airborne resets and non-back-first crossings.
3. Scene and data: G1 with original torque limits, ground, supported movable bar, and compliant-contact landing mat. Produce smooth crouch/push/back-arch/leg-clearance/landing reference; save source parameters and kinematic preview explicitly labeled reference.
4. Training: start with tracking, reference-state initialization only during training, full grounded starts for evaluation. Add task rewards/penalties and progression based on measured success. Save logs and checkpoints.
5. Transfer: write exact compiled model and observation/action contract; frozen inference with standard MuJoCo, no teleporting or external forces. Save trajectories, contacts, torque saturation, whole-body clearance and backward orientation.
6. Acceptance: full ground-start episode, both feet lose ground contact, whole collision geometry passes above and between bar ends, no bar contact, upward-facing torso during crossing, mat landing. Multiple seeded trials. Report highest verified bar and actual success count; never label an incomplete run as success.
7. Deliver H.264 MP4, checkpoint, runnable commands, metrics and report; update local WORKSPACE_CHANGES.md. Training is experimental; success is not presumed.

User constraint: final crossbar center height is exactly 0.80 m; lower curriculum heights do not fulfill acceptance.
