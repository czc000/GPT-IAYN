# G1 0.8 m 跳高：状态反馈 PPO

用户要求的是读取机器人状态、在线输出关节目标的策略。旧 CEM 结果只作参考与固定目标对照，不作为新要求的最终结果。

## 方法与控制链

`scripts/prepare_rl.py` 通过真正的 native MuJoCo 动力学执行旧控制器，保存控制边界的状态、关节目标、姿态和速度。该示范的根部轨迹只进入训练奖励/critic；评估过程中不把参考根部状态写入机器人。

策略有两个实验架构：

- 普通参考条件 PPO 残差 actor；含带观测归一化的版本。
- `FeedbackActor`：同一 MLP 分别读取实际状态与对应参考状态，取输出差作为残差。参考状态下残差为浮点精度内的零，迫使高层均值修正依赖当前状态偏差。仍然是参考条件残差策略，保留示范目标作为前馈。

每 20 ms 运行一次冻结 TorchScript。导出模块整体输出 29 个绝对关节目标角；每 2.5 ms 根据实际编码器 q/dq 计算关节 PD，并裁剪到 DC 电机转矩–转速包络。机器人浮动基座不受任何策略直接写入、外力扶持或中途重置。

## Actor 输入契约（152 维）

| 范围 | 输入 | 部署来源 |
|---|---|---|
| 0:29 | 示范目标关节角 | 本地参考文件 |
| 29:58 | 示范实际关节角 | 本地参考文件 |
| 58:87 | 示范关节速度 × 0.05 | 本地参考文件 |
| 87:116 | 当前关节角 − 示范关节角 | 编码器与参考文件 |
| 116:145 | 当前关节速度 × 0.05 | 编码器 |
| 145:148 | 骨盆坐标系重力方向 | IMU 姿态估计；仿真中为理想姿态 |
| 148:151 | 骨盆角速度 × 0.1 | IMU 陀螺仪 |
| 151 | 动作相位 k/130 | 控制器时钟 |

Actor 不输入世界位置、世界线速度、足端世界坐标或接触真值。上述真值可以用于训练 critic/奖励。参考文件是动作指令，不是对机器人实际状态的特权测量。实机部署仍需匹配 IMU 坐标系、关节顺序、估计误差、时延及硬件限制；本项目没有操作实机。

## 验证与诚实边界

- GPU/native 100 步观测一致性；自动 reset 后第 0 帧对齐测试。
- 契约测试验证 actor 对全局平移和线速度不敏感、对编码器变化敏感、导出目标与限位一致。
- 差分 actor 测试验证参考状态零修正、偏差状态梯度有效、TorchScript 相位索引保持动态。
- 固定目标、普通 PPO、纯反馈 PPO 使用相同 native 物理场景和严格验收。全部保存网络输入、目标角与实际轨迹。
- 消融将高层 actor 的实测输入替换为对应参考状态；底层关节 PD/DC 反馈仍保留，不能称为关闭了所有反馈。
- native 视频在实时执行网络和 `mj_step` 的同一个循环渲染，不是把保存的 qpos 逐帧写回。
- MuJoCo-Warp → native MuJoCo 是计算后端迁移，不能表述成跨物理引擎成功。Isaac/PhysX 后续经 0.5 反馈增益标定完成一条在线录像成功回合，详见 docs/history/PPO_RESULTS.md；这不是零样本迁移。

初版普通 PPO 的在线 nominal 已通过，但扰动结果与去掉高层反馈的消融相同，不能据此宣称学会了有效纠错。最终结论必须引用后续冻结模型的独立指标。

最终交付在原始权重外使用 0.5 常量反馈增益。PhysX 录像经实际接触日志和精确碰撞几何复核，最小间隙 1.8945 mm；native 较大扰动鲁棒性仍不足。完整独立统计见 docs/history/PPO_RESULTS.md。
